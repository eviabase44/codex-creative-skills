Installing this folder installs instructions, references and helpers. It does not connect Figma, an image/video generator, Slack, Drive, a brand plugin or After Effects. Use tools actually available to the user; verify model-specific controls before relying on them. Python helpers require Python 3.10 or later; video extraction and encoding require FFmpeg and FFprobe on PATH. Python helpers use the standard library.

Paths to scripts/assets are relative to this skill's installed root. Run its command examples from that root, or pass absolute script paths. ## Camera, cuts and performance

For each source shot record framing, size, angle, observable lens character, camera movement, subject position, light source/direction and start/end states. Separate fixed character identity from changing hands, props, wardrobe state and eyeline. Preserve the axis, screen direction and light-source geometry across cuts. Label inferred lens/camera metadata as estimates.

Name the technique actually present and its story purpose. Design joins using matched outgoing/incoming position, scale and motion direction. Source recreation preserves source cuts and timing; do not add effects to make a faithful reconstruction more flashy. For original sequences choose restrained, motivated techniques and distinguish in-shot generation from editorial work. Verify actual model support.

For a performance, identify the stimulus, what the person attempts, and the observable response. Keep gaze spatially coherent, gestures appropriate to framing and reactions after their cause. Preserve supplied dialogue and starting/ending prop states. Inspect actual moving footage for timing; stills cannot establish speech or performance continuity.

## Reference fidelity and motion evidence

Inspect actual source pixels and native timestamps before using a title, thumbnail or inherited description as evidence. Record source identity/hash and selected frame/interval, lock composition and material, map every replacement, and fit content to the original slots. Image Copycat edits a source design; Copycat v3 explicitly rebuilds from new editable layers and does not retain source backplates.

Measure camera, viewport, object and cursor motion separately at native cadence, including intermediate poses, onset, holds, cuts, scale, rotation/depth, clipping and occlusion. Endpoint interpolation does not prove a trajectory. Keep observations separate from estimates. Validate a moving pilot before scaling.

Copycat v3 samples by elapsed source time at 12 fps; it does not slow native footage down. Keep frame-valued controls in native FPS. Do not invent generic easing, optical flow, blended frames or flat-sprite depth turns. The Present Flow bridge verifies records and exports evidence; exact AE evaluation requires compatible native software or validated samples.
