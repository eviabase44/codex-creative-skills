# Known issues and handoff limits

## Preserved expression errors

`Base44_Templates_01_Title_Only_v01 2` has eight [ORG] word Position expressions reporting `offsetAuthored is not a function`. They were already disabled when inspected. The 24 log entries are three samples of each of eight properties, not 24 separate defects. Do not promote this variant to a reusable template until repaired and visually reapproved. No animation code has been silently repaired.

## Extraction limitation

The `Opening 2` layer in `Title_on_BG_02` produced a property traversal exception. Its layer identity and explicit effects were still captured; the original AEP retains all properties. Treat its general property dump as partial. Inspection JSON is not a full AEP serializer.

## Media collection — resolved

The two mounted-drive textures initially stalled during collection. The user supplied local copies in Downloads; both were collected and relinked. All 36 file-backed footage items now resolve inside `approved/media`. Original/current-state snapshots retain provenance links intentionally; use `Approved-packaged.aep` for handoff. Fonts are not bundled.

## Validation scope

Approval folder membership is user acceptance, not an assertion of zero errors. Readable expressions were sampled at start, midpoint and end; explicit controller expressions and nested effects were extracted but not all independently evaluated by the inspection pass. Still previews are spot checks, not full motion reviews. Fonts are listed but not redistributed. Original generating JSX cannot be recovered from an AEP; extracted expressions are exact, while historical builders are provenance references only.

## Excluded reference

SH20 arc rigs are excluded from reference selection and were not copied into the historical builder set. The source AEP may retain unrelated project items; only the approved catalog defines the reference set.
